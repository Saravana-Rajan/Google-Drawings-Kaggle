## Key takeaways

* **Claude Opus 5.5** (openhands) leads the 56 hidden test tasks
  at 0.486. On the same model, **claude-code** (0.483) and
  **agy** (0.477) are within run-to-run variation.
* The model matters most. Averaged across all seven
  harnesses, model scores range from 0.003 (Llama 4 Maverick) to
  0.473 (Claude Opus 5.5), whereas switching harnesses on a single model
  shifts its score by up to 0.184 (DeepSeek-V4.1-Flash, codex to opencode).
* Cost varies far more than score on one model. On **Claude Opus 5.5**, a task costs 3×
  as much with **agy** ($42.32) as with
  **opencode** ($12.87). The top-scoring pair, **Claude Opus 5.5** (openhands), costs $14.87 per task.
* Different pairs lead different disciplines: **Opus 5.5** (openhands) in structural, **Opus 5.5** (claude-code) in civil, **Opus 5.5** (hermes) in electrical and **GPT 6 Astra** (codex) in mechanical.

## How the models were run

Every model runs all 85 tasks on each of its harnesses (6 hours per task). Each pair runs three times, and its score averages its
complete runs.
Each model runs at its highest available reasoning effort.

Harnesses run at fixed releases:
agy 1.3.3, claude-code 2.1.296, codex 0.162.1, hermes 0.22.2, opencode 2.0.26, openhands 1.54.0, pi 1.1.0, grok-build 1.0.52 and dsh 0.2.1-alpha.4.

Cost per task is calculated from token usage at list prices, including cached reads.

:   adaptive thinking at effort max (Opus 5.5, Sonnet 5.5, Opus 5, Fable 5); reasoning effort max (GLM 5.2, DeepSeek-V4.1-Flash, GPT 6 Astra)

n/a
:   no reasoning setting (Qwen3 Coder 480B, Qwen3-Next 80B, Llama 4 Maverick)

thinking on
:   thinking enabled (Gemma 4 26B)

## How grading works

Each task runs in an isolated container with the project's drawings, spreadsheets, specs, and local services.

Automated scripts check quantitative outputs, while an LLM judge grades open-ended engineering work against
an expert rubric.

* No internet access
* 6 hours per task
* Three runs per harness and model
